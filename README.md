# Gengold Eye Wonder+ — Vercel + Firebase Lead Site

Premium Meta-ad landing page, protected admin dashboard and Vercel serverless API backed by Cloud Firestore.

## What is included

- `index.html` — premium landing page with responsive animations, video hero, lead form and WhatsApp CTA.
- `admin.html` — protected lead dashboard at `/admin`.
- `api/submit.js` — saves lead submissions to Firestore.
- `api/leads.js` — authenticated lead retrieval.
- `api/settings.js` — public WhatsApp lookup + authenticated WhatsApp update.
- `api/admin-key.js` — authenticated admin-key change endpoint.
- `lib/firebase.js` — server-only Firebase Admin SDK helper.
- `.env.example` — Vercel environment-variable template.
- `assets/` — supplied campaign video and product imagery.

## 1. Create the Firebase project

1. Open the Firebase Console and create a project.
2. In **Build → Firestore Database**, create a Cloud Firestore database.
3. Choose **Production mode**. This project accesses Firestore from the Vercel server using the Firebase Admin SDK, so client-side Firestore rules are not used by these API routes.
4. Go to **Project settings → Service accounts**.
5. Choose **Generate new private key** and download the service-account JSON. Keep it private.
6. Copy these values from the service-account JSON into Vercel environment variables:
   - `FIREBASE_PROJECT_ID` → `project_id`
   - `FIREBASE_CLIENT_EMAIL` → `client_email`
   - `FIREBASE_PRIVATE_KEY` → `private_key`
7. Set `ADMIN_BOOTSTRAP_KEY` to `gengold321` for the first deployment.

Never put the service-account JSON, private key, or service-account email in `index.html`, `admin.html`, GitHub, or any browser JavaScript.

## 2. Deploy to Vercel

Import this project into Vercel. Add the four environment variables above for Production (and Preview if you want preview deployments to have database access).

The first API call creates the Firestore document:

`app_settings/general`

Leads are stored in:

`leads/<auto-generated-id>`

The initial admin key is `gengold321`. After logging into `/admin`, change it from the **Change admin key** section.

## 3. Admin dashboard

Open:

`https://YOUR-DOMAIN/admin`

Initial key:

`gengold321`

Inside the dashboard you can:

- View leads
- Search leads
- Export CSV
- Change the WhatsApp number used by all CTAs
- Change the admin key
- See Meta UTM/fbclid attribution when supplied

## 4. Recommended domain

For this campaign, use:

`eyewonder.okharmart.online`

It is short, brand-relevant and immediately connected to the Eye Wonder+ product while still inheriting the credibility of `okharmart.online`.

## 5. Namecheap → Vercel

1. Deploy the project to Vercel first.
2. In Vercel, open **Project → Settings → Domains** and add:
   `eyewonder.okharmart.online`
3. Vercel will show the DNS record/target for the subdomain.
4. In Namecheap, open **Domain List → okharmart.online → Manage → Advanced DNS**.
5. Under **Host Records**, add a **CNAME Record**.
6. Host: `eyewonder`
7. Value/Target: use the exact CNAME target Vercel shows for the project (Vercel commonly uses a project-specific `vercel-dns` target).
8. TTL: Automatic.
9. Save.
10. Return to Vercel and wait for the domain to become verified.

Do not type the full `eyewonder.okharmart.online` into the Namecheap Host field; Namecheap expects only `eyewonder` for this subdomain.

## 6. Meta Ads attribution

The landing page captures:

- `utm_source`
- `utm_medium`
- `utm_campaign`
- `utm_content`
- `utm_term`
- `fbclid`

Example:

`https://eyewonder.okharmart.online/?utm_source=facebook&utm_medium=paid_social&utm_campaign=gengold_launch&utm_content=video1`

Those values are saved with each lead and shown in the admin dashboard.

## Important product/advertising note

Keep Meta ad copy and landing-page claims consistent with your approved product/label documentation and applicable advertising rules. The landing page is intentionally written around general eye comfort rather than promising treatment or cure of diagnosed eye diseases.


## Production deployment checklist

1. Keep `.env.example` as a template; never commit a real `.env` or Firebase service-account JSON.
2. In Vercel, set `FIREBASE_PROJECT_ID`, `FIREBASE_CLIENT_EMAIL`, `FIREBASE_PRIVATE_KEY`, and `ADMIN_BOOTSTRAP_KEY` for the environment being tested.
3. Redeploy after changing Vercel environment variables.
4. Test the live `/admin` URL and the landing-page form on the deployed domain.
5. The email field is optional. If supplied, it is validated in both the browser and API and saved to Firestore.
